# Feature Spec: Merge CSV Files

## 1. Goal
Add a new feature to merge multiple CSV files into a single CSV file. Users can select files from their processing history or upload new files directly.

## 2. User Interaction
- **New Tab**: Add a third tab "Merge CSVs" (合并 CSV) alongside "Excel/CSV to JSONL" and "JSON to Excel/CSV".
- **File Selection**:
  - **From History**: Display a list of CSV files available in the history (files generated by previous "JSON to Excel/CSV" operations or even uploaded ones if we tracked them, but currently history tracks outputs. So mainly outputs from JSON->CSV conversion, or maybe we allow re-using inputs? The user said "history records' csv files", likely referring to the outputs generated by the tool, which are stored in OPFS).
  - **Upload New**: A file input area to upload multiple `.csv` files from the local file system.
- **Selected Files List**: Show a combined list of files selected for merging. Allow removing files from this list.
- **Merge Action**: A "Start Merge" button.
- **Output**:
  - Progress indicator.
  - On completion, show success message.
  - "Download Merged CSV" button.
  - Save the merged result to History (so it can be downloaded later).

## 3. Technical Implementation
- **State Management**:
  - `activeModule`: Add `'merge_csv'`.
  - `mergeFiles`: Array of file objects or references to OPFS files.
  - `mergeStatus`: 'idle', 'processing', 'completed', 'error'.
- **Logic**:
  - Reuse `PapaParse` for CSV parsing.
  - **Merging Strategy**:
    - Parse all selected CSVs.
    - Check headers.
      - **Scenario A (Same Headers)**: Simple concatenation.
      - **Scenario B (Different Headers)**: Union of all headers. Missing columns filled with empty strings.
    - Write to a new OPFS file.
  - **Worker**: Use a new Web Worker (`mergeWorker.ts`) to handle parsing and merging to avoid blocking the UI, as files can be large.
- **Constraints**:
  - Do not modify existing `excel_to_jsonl` or `json_to_excel` logic.
  - Ensure memory efficiency (stream processing if possible, or chunked). given the environment, we might load full files if they are not huge, but streaming is safer. `PapaParse` supports streaming.

## 4. UI/UX
- Follow existing design language (Tailwind CSS).
- Use existing components where possible (Buttons, File inputs).
- Provide a preview link after implementation (using `OpenPreview`).

## 5. Verification
- Test with 2 CSVs with same headers.
- Test with history files + uploaded files.
- Verify download works.
